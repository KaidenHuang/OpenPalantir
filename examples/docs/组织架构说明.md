# 平台工程部组织架构说明

## 部门定位

平台工程部负责公司内部工具与数据平台的建设，现有正式员工 12 人，向技术总监王涛汇报。部门下设两个小组：数据平台组与工程效能组。

## 人员与岗位

- **张明**：数据平台组组长，职级 L3，负责指标口径与数据服务。
- **李芳**：工程效能组组员，职级 L2，负责 CI 流水线与发布工具。
- **陈立**：数据平台组组员，职级 L2，负责调度系统与作业稳定性。
- **周雨**：工程效能组组长，职级 L3，负责研发度量与内部工具推广。

## 职级说明

公司技术序列分为 L1 至 L5。L2 为独立完成模块的工程师，L3 为能带小团队并定义技术方案的人。职级评审每半年一次，由技术总监王涛主持，评审结论记入人事系统。

## 汇报关系

张明、周雨直接向王涛汇报；李芳、陈立分别向所在小组组长汇报。跨组协作时，由周雨统一对齐工程效能侧的排期。
