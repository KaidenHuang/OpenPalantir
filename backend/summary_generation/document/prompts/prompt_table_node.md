# 表格摘要与列标注任务

## 任务描述

你是一个业务数据建模专家。输入是一个或多个 Excel/CSV 工作表的「表档案」，每个档案包含：
工作表名、规模（行列数）、列清单（`列名(类型)`，类型为 TEXT/NUM/DATE/BOOL/EMPTY）与少量样本行。

对每一个工作表，一次完成四件事：

1. **摘要**：一段话说清这张表记录的是什么业务对象、什么粒度（一行代表什么），以及关键字段口径。
2. **列角色**：判断每一列属于
   - `entity`：列的取值本身就是可独立复用、在别处会被引用的业务对象，应当建为图谱节点（如部门、省份、产品、客户、期间）；
   - `attribute`：列的取值只是描述主实体自身的档位或度量，挂在主实体上（如金额、数量、占比、职级这类枚举档位、备注中的度量）。这类列**不要**建节点——同一档位会被多行重复引用，图谱会被取值淹没；
   - `none`：无业务含义或不值得入图（流水号、序号、排版占位、合计行文本）。
3. **列间关系**：两个 `entity` 列在同一行里同时出现，**且业务归属能从表名、列名直接读出**时，才输出到 `rels`。同行共现本身不是连线理由；例如「为某部门提供服务的外部公司」不能读成「该部门属于这家公司」。
4. **主实体列**：`primary` 填该表一行所代表的那个业务对象对应的列名，必须是 `r=entity` 的列之一。

## 语言一致性要求

输出语言必须与输入表名的语言保持一致。输入是中文时，`summary` 与 `d` 必须使用中文。

## 输出格式

只返回如下 JSON，不要添加任何额外文本、解释或代码围栏：

```json
{
  "sheets": [
    {
      "title": "工作表名（与输入完全一致）",
      "summary": "该表的业务摘要",
      "columns": [
        { "n": "列名", "r": "entity", "t": "organization", "d": "该列的业务含义" },
        { "n": "销售额", "r": "attribute", "d": "当月实际销售额，元" },
        { "n": "备注", "r": "none", "d": "自由文本，无业务含义" }
      ],
      "rels": [
        { "s": "部门", "p": "属于", "o": "省份" }
      ],
      "primary": "部门"
    }
  ]
}
```

## 格式要求（请严格遵守）

1. **逐列覆盖**：`columns` 必须列出输入表档案【列】里出现的每一列，列名与输入逐字一致，不合并、不改写、不新增。
2. **取值范围**：`r` 只能是 `entity` / `attribute` / `none`；`r=entity` 的列必须给 `t`，选不中候选项时填 `other`。
3. **关系约束**：`rels` 的 `s` 与 `o` 必须是本表 `r=entity` 的列名，`p` 必须是关系类型选项里的 key，选不中填 `其他`。
4. **主列约束**：`primary` 必须是本表 `r=entity` 的列名之一；该表没有任何 entity 列时填空字符串。
5. **一个工作表一个对象**：输入有几个表档案，`sheets` 就输出几项，顺序与输入一致。
6. 所有值都是字符串或对象/数组，不要输出注释、尾随逗号或未加引号的键。

### 输入示例

```
【工作表】月度汇总

【样本】
| 部门 | 省份 | 销售额 | 月份 |
|---|---|---|---|
| 华东大区 | 浙江 | 1203400.5 | 2025-01-01 |
| 华北大区 | 北京 | 980200 | 2025-01-01 |
```
